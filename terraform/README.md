# AWS scaffold

No resources are defined or deployed in phase 1. Design and price a minimal deployment before adding resources. Do not run `terraform apply` without explicit permission. Avoid NAT gateways and managed services that exceed the budget. Keep credentials out of files and version control; Terraform state can contain secrets and is ignored. Before any future deployment, estimate all regional charges, configure AWS Budgets alerts (alerts are not hard spending caps), and record start time. After permission and deployment, use `terraform destroy` with the same configuration and verify resources are gone in the AWS console; check Cost Explorer/billing for delayed charges and confirm any budget alerts. Resource deletion does not erase charges already incurred. No AWS calls are needed for this phase.
